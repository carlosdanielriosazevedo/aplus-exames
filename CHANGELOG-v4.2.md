# v4.2 — Beta Privada com Amigos

- Entrada própria com aviso explícito de teste de experiência.
- Conteúdo ainda em revisão pode ser usado para UX, sem alterar o GO/NO-GO pedagógico.
- Variantes geradas continuam desligadas fora do modo interno.
- Índice, Domínio, Certeza e nota são marcados como provisórios.
- Código pseudoanónimo único `AMG-XXXXXX` por tester.

- Relatório não inclui nome nem email.
- Feedback adicionado também ao fim do diagnóstico.
- Conta/cloud escondida neste piloto para reduzir distrações.
- Storage da beta de amigos isolado do storage normal.
- Rascunhos de sessões também isolados.
- Corrigida a hidratação: estado só é gravado depois de terminar a leitura inicial.
- Novo `npm run friends-beta:audit`.
- Gate técnico passa a validar a beta de amigos.
