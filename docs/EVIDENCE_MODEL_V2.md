# Evidence model v2 — invariants

1. One correct answer never yields high certainty.
2. Four independent, varied and consistent items must yield more certainty than four variants with the same semantic signature.
3. Contradictory independent evidence lowers certainty before it causes a large domain swing.
4. Old evidence still contributes to domain, while certainty becomes more conservative.
5. Exam evidence carries more assessment weight than mission evidence; mission evidence carries more than diagnostic evidence.
6. Causal prerequisite probes may reduce the strength assigned to the target error, but never erase it.
