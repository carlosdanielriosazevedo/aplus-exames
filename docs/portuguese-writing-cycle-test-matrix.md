# Matriz de testes — ciclo de escrita

| Caso | Estado esperado |
| --- | --- |
| Parcial → Cumpri | melhoria autoassinalada |
| Ainda não → Parcial | melhoria autoassinalada + mantém atenção |
| Cumpri → Parcial | reconsideração + mantém atenção |
| Cumpri sem evidência | pedir evidência concreta |
| Evidência A → Evidência B | evidência revista, sem inventar subida |
| Todos Cumpri + evidência | consolidação |
| Sem estado | próximo critério pendente |
| Critérios vazios | resultado vazio e seguro |

Em nenhum caso a saída é convertida em nota, percentagem ou juízo automático de correção.
