# v2.9 — Diagnóstico causal de dificuldades

A app deixa de assumir que um erro numa competência avançada nasceu necessariamente nessa competência.

## Exemplo
1. O aluno erra uma questão de monotonia usando derivadas.
2. A Missão faz uma verificação curta de derivadas.
3. Se também falhar, “Derivadas” passa a ser uma hipótese de causa.
4. O erro original recebe peso reduzido no foco mais avançado.
5. Se a base responder bem, ganha força a hipótese de uma dificuldade específica no foco original.

## Segurança pedagógica
Uma única pergunta nunca confirma uma causa. A interface usa linguagem como:
- causa provável;
- hipótese;
- a investigar.

A memória só fortalece uma hipótese após verificações independentes.

## Dependências por competência
Primeiro grafo para cálculo diferencial, continuidade/derivabilidade,
probabilidade e exponenciais/logaritmos.

## Conteúdo
Foram adicionados 8 probes originais curtos, todos com estado editorial `prototype`.
Não são questões oficiais do IAVE.
