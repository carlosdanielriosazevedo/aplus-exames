## Regras editoriais

- Nenhum item deste diretório é automaticamente elegível para Diagnóstico, Missão ou Mini-exame.
- Todos entram como `prototype`.
- Um lote com 50 perguntas não significa 50 evidências independentes: perguntas estruturalmente semelhantes partilham `signature`.
- Alterar apenas números não conta, por si só, como nova pergunta editorial.
- Cada lote procura variedade de compreensão, aplicação, interpretação, raciocínio, modelação e dificuldade.
- Antes de integração: QA matemático + QA estrutural + revisão pedagógica adequada à política em vigor.
- Não copiar/adaptar perguntas, textos, figuras ou critérios IAVE.
